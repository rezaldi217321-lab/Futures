# FUTURES ROBOT AI

Website statis (1 file `index.html`). Data publik OKX + chart TradingView. Bukan nasihat keuangan.

## GitHub
1. Buat repo baru, upload `index.html` dan `README.md` ke branch `main`.

## Cloudflare Pages
1. Dashboard Cloudflare → Workers & Pages → Create → Pages → Connect to Git → pilih repo.
2. Framework preset: None. Build command: kosong. Build output directory: `/`.
3. Deploy. Setiap push ke GitHub otomatis ter-deploy.
